## 中文详细说明（直接粘贴到商店后台）

Element Print 是一个面向阅读、摘录和打印的浏览器扩展。它可以手动点选网页元素，或自动识别整页正文，把文章、论文、报道、书评、资料摘录提取为可调整版式的预览页。

主要功能：

- 手动选取或整页自动提取正文，保留标题、段落、列表、表格、引用、链接和图片等富文本结构。
- 提供报纸原版、学术期刊、公文三套版式；支持单栏/双栏、字号、标题字号、行距、段间距、首行缩进、四边页边距和页眉页脚开关。
- 适配 A4 纸、10.3 英寸电纸书和手机阅读三种输出对象；版式与页面格式分别记忆。
- 支持中英混排还原、原文视图、左右双语对照；手机端自动转为上下串行翻译。页面自带译文可自动配对，缺失译文可通过 DeepL 或百度翻译补发。
- 预览页可直接打印为 PDF，也可导出图片内嵌的单文件 HTML，便于离线保存和二次排版。
- 标题、摘要、作者、日期等元信息可在预览页直接编辑；摘要优先读取页面可见 Abstract，并自动匹配页面自带译文。

适用场景：论文摘要与正文摘录、长文章打印、网页资料归档、双语对照阅读、电纸书和手机阅读排版。

隐私说明：扩展不存储浏览历史；翻译请求按选择的引擎发送需要翻译的文本；API 密钥仅保存在本机浏览器存储中。

## English detailed description

Element Print extracts webpage content for reading, note-taking, and printing. Select an element manually or auto-extract the main article, then adjust a print-ready layout before printing to PDF or exporting a single-file HTML.

Features:

- Manual selection or Readability-based full-page extraction; preserves paragraphs, lists, tables, quotes, links, and images.
- Newspaper, academic journal, and official document templates; adjustable columns, font size, title size, line height, spacing, indentation, margins, headers, and footers.
- Built for A4 paper, 10.3-inch e-ink readers, and mobile reading; layout preferences are remembered separately by output format.
- Mixed bilingual view, source view, and side-by-side translation; mobile uses stacked source and translation. Existing translations are paired automatically; missing translations can be completed through DeepL or Baidu Translate.
- Print directly to PDF or export a self-contained HTML with embedded images.
- Edit title, abstract, author, and date directly in the preview; visible abstracts are preferred over truncated metadata descriptions.

Use it for paper excerpts, long-article printing, web archiving, bilingual reading, and e-reader or mobile layouts.

Privacy: the extension does not store browsing history. Translation requests send only the texts selected for translation; API keys are stored locally in browser storage.
